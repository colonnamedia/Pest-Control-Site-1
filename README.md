# ClearPath Pest Solutions — FireWorks Demo

Reusable recurring-property-services website template, starting with pest control and designed for adaptation to cleaning and lawn care.

## Run and test

Open `index.html` with any static server. Run `npm test` to verify internal links, metadata, demo-form safety, and required project documentation.

All business details are demo content. See `FIREWORKS-PROJECT.md` for pricing, integrations, client inputs, and adaptation notes.
